# TaskPilot – Angular + Kotlin/JS

Local-first task manager built for the framework comparison (see `../../SPEC.md`).
UI: Angular 22 (standalone components, signals, SSR + hydration). Logic: Kotlin compiled to an ES-module
library with Kotlin/JS (`core/`).

See [RUN.md](RUN.md) for build/run instructions and [DEVLOG.md](DEVLOG.md) for the development log.
